# Artwork Notes

The presentation cover was created with Codex's **built-in imagegen tool**. The supplied reference was the official KizuBot mascot, fetched from [kizubot.com](https://www.kizubot.com/images/logo-principal-kizubot.png). The original branding image is preserved as `assets/kizubot-logo.png`.

The cover extends that reference into a wide illustration with the seated purple robot, three portrait film frames and a short editorial title. The illustrated pixel-art scenes are conceptual artwork. The README gallery separately uses selected frames from real KizuBot deliveries.

Final cover: [`assets/kizubot-social-cover.png`](assets/kizubot-social-cover.png).

The original generated output was retained in Codex's generated-images storage, and a complete copy was placed in this package. No fallback CLI or external image API was used.

## Final prompt

```text
Use case: ads-marketing.
Asset type: a premium wide GitHub README cover for KizuBot Social, 2:1 horizontal composition.
Primary request: expand and recompose the supplied official KizuBot logo artwork into an original editorial cover about turning real gameplay into short videos.
Input image 1: official KizuBot mascot reference and edit target. Preserve the recognizable seated gunmetal-and-silver robot, its single circular purple eye, segmented limbs and tablet. Keep it clearly the same mascot. Integrate its upper body on the left third; remove the huge bottom logo plaque from this new composition.
Scene/backdrop: deep near-black aubergine studio with fine violet circuit traces, subtle film-grain, carefully restrained purple rim light. On the right, an elegant fan of three portrait film frames containing stylized original top-down pixel-art forest, rocky trail and combat-light motifs. These are abstract conceptual illustrations, not replicas of a real game interface.
Composition: generous editorial breathing room. Big crisp off-white display typography in the upper-right half. Robot and three portrait frames give a balanced, memorable silhouette. A thin magenta editorial line ties the frames to the title. A small horizontal film-strip detail at the bottom suggests cuts and storytelling.
Text (verbatim): "KizuBot Social" as the large title; "Real gameplay. Short stories." as a smaller subtitle; "kizubot.com" as a discreet footer.
Typography: refined bold geometric sans, impeccable spelling, readable at 900 pixels wide; do not add any other words.
Color palette: near-black #0B0712, rich violet #A855F7, lavender #D8B4FE, warm white #F5F0FA, tiny warm-yellow accent. Matte painted illustration and polished editorial finish, coherent with the reference mascot.
Constraints: sharp elegant artwork, full opaque background, no personal information, no customer names, no chats, no charts or statistics, no product guarantees, no watermarks, no stock photography, no unrelated platform logos, no recognizable copyrighted game creatures, no fabricated application screenshots, no extra mascots.
```
