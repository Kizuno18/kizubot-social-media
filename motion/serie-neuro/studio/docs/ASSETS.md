## How to use

- **Paths.** Every path in this file is relative to a short's folder (`shorts/NNN-slug/`, where `kit` is a symlink): write `kit/img/prints/<file>` exactly as listed.
- **Card + tag.** Show every customer print inside a card (`.kz-card`) with the small tag `.kz-print-tag` saying **"print real de cliente"**. Exceptions are flagged in *notes*:
  - prints of the owner's own posts (`inventario-multi-recursos*`, `todo-dia-isso-bixo.png`): tag them **"print real"** (no "de cliente");
  - focus crops that show only the owner's words (`gym-smartwatch-alarm--quote`, `quem-farmava-muito-vai-farmar-mais--segredo`, `suporte-ajusta-sua-config--config`): tag **"print real"**;
  - memes (`meme-*`): never tag them as testimonials.
- **Quotes are verbatim only.** If you set a quote in big type, copy it exactly from the *verbatim* column, typos included ("é a perfeiçã ocara", "trapa", "inten de finders", "mechendo", "dês do começo"…). You may trim a quote, but never reword it, fix it or add words. The original print should appear on screen at least once with the quote. Quote what the **image** says, not the caption on kizubot.com: several site captions don't match their screenshots (see *Site caption errors* below).
- **Never combine prints from different customers** in one frame or sequence without saying so on screen (e.g. "clientes diferentes"). All files sharing a slug come from the same print, so they are the same customer. Same customer across different slugs: `mamao-com-acucar` = `antes-hardcore-hoje-tranquilo`; `licenca-acabou-renovei` = `farmou-1700-dd-2-chars`; `insano-o-update` = `insano-o-update--sensacional` (shown separately because a profanity bubble sat between them); `parece-que-sei-programar*` (2 screenshots of the same chat). Prints that include **two people**: `boss-metagross-metal-coat` (the reaction is another member), `shiny-dratini-new-server` ("Esse aí tirou onda" is another member), `beach-satire-group` (customer + another member), `hamburguer-no-sofa` (the question is from another member), and owner lines in many chats. `backpack-pilhas-10k` and `so-desligo-quando-pegar` may be **different** customers.
- **Redactions are intentional and must stay.** Solid rounded pills in the bubble colour and mosaics hide names, nicks, avatars, faces, profanity and money or ban lines. Never remove them, recolour them, crop a pill in half so it looks like text, caption what is under them, or run "AI enhance/upscale" on any print (it can rebuild hidden detail).
- **Resolution.** Crops narrower than 900 px were upscaled with Lanczos (max 3×, max 1080 px wide). A width under ~1000 px means a tiny source: show it smaller than full width. Strips like 1080×57 are single chat lines. Files taller than 1920 px need a pan/scroll or one of their `--` focus crops. Files 1500–1634 px wide are wide desktop screenshots: use their focus crops.
- **Numbers are in-game only.** "kk" = millions of in-game money, "kkk" = billions; "dl"/"dollars" is PxG's in-game currency. Never show R$/$/€ next to them, never convert them to real money, and never pair them with money emojis or money visuals. Arithmetic is fine only on numbers visible in the print (e.g. 10k × 750 = 7.5kk, as the owner wrote in `20kk-de-profit-hoje`). Label `900kk-em-30-dias-estimativa` as **"estimativa do cliente"**. "dd" (diamonds) is a premium, real-money-adjacent currency: don't headline it.
- **Plans.** BRIEF.md's current plans are **Base** (R$ 250/mês) and **Premium**. Some prints mention "vip2" (and "premium" in a multi-machine context): those words may stay inside a verbatim print, but never name "vip2" as a plan on screen or in captions.
- **Old UI.** Every panel screenshot in `kit/img/ui/` and the HUD in `hud-8434-loots` show an **old UI. Never present them as the current panel.** Use them only as historical or background texture, or labelled "interface antiga".
- **Never use** anything from *Excluded files* below, and don't re-add it from `lp-kizubot/public/media`.
- **Verification status: pass 2 done.** Every file here was checked twice for names, faces, phone numbers, links, nicks, avatars and profanity: once right after it was made, then again across the whole final set. Pass 2 changed only these files, in place with the same names: `beach-satire-group.png` (a character name inside the meme thumbnail) and `boss-metagross-metal-coat.png` + `print real` (the sender's profile avatar inside the forwarded screenshot). Just before pass 2, `meme-mochileiro-whisper.png` + `print real` also got their character name covered. If you exported frames of these files before, re-export them.
