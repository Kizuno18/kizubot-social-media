# F02 — POV (046–050)

**Lever:** self-reference ("you" stories are processed and remembered better), narrative transport, then social proof with the real print as the twist. POV is a native TikTok format: the viewer *is* the protagonist.
**Look:** phone-first. A big "POV:" caption in TikTok style (white text on a dark rounded box or bold outline), real-feeling props: a lock screen with stacked notifications, a dim bedroom, a gym timer, a beach-bright palette — each episode its own mood and color temperature. The phone UI is generic (no WhatsApp logo); notifications say "KizuBot™ | kizubot.com" exactly as in the real alarms. Real prints appear inside a card tagged "print real de cliente".
**Music:** lofi for the setup, then a drop (house/phonk) on the reveal; `notif`/`alert` on every notification, `heartbeat` for tension.
