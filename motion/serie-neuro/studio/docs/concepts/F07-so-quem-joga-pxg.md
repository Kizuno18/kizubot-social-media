# F07 — Só Quem Joga PxG Entende (071–075)

**Lever:** in-group identity and humor. Inside jokes signal "this is for us", which drives sends/shares ("marca o amigo que…") — the strongest distribution signal on all three platforms. Memes are fast to read (processing fluency).
**Look:** meme formats rebuilt in code (no copyrighted meme images, no stock faces): classic top/bottom caption (Anton, white with black stroke), "Ninguém: / Eu:", "Expectativa x Realidade" split, tier-free classification cards, reaction stickers with emoji (Noto), Discord-ish dark chat crops from real prints. Raw, punchy, a little chaotic on purpose — but still in the safe zone and readable.
**Music:** funk (130) or phonk (130); `scratch`, `glitch`, `boom`, `pop`.
