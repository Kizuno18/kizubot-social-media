# F08 — Ligação Recebida (076–080)

**Lever:** pattern interrupt. An incoming-call screen triggers an automatic orienting response (our brains are trained to react to a ringing phone), so the first second is unskippable; the call metaphor then personifies the bot/char and delivers a real alarm as the "news". The ringtone is the KizuBot motif (`motif` SFX looped) — sonic branding again.
**Look:** generic smartphone UIs designed from scratch (no iOS/Android/WhatsApp trade dress): incoming call with a round avatar (the KizuBot head crop), caller name, slide-to-answer, call timer, voice-note bubble with an animated waveform, video-call frame, missed-calls list, alarm-clock app. Big readable captions as the "voice" (the bot never speaks out loud; it's text).
**Music:** start with the motif ringtone (no beat) for 1–2 s, the beat drops when the call is answered (lofi/house/phonk); `click` on answer, `notif`/`alert` on news.
