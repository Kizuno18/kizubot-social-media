# F10 — Você Prefere? (086–090)

**Lever:** forced choice + contrast effect: two options side by side make the better one obvious (and the comment "B" costs nothing → comments are an algorithm signal). The twist at the end: "na real, com KizuBot dá os dois".
**Look:** split screen A (top, red/warm) vs B (bottom, violet/cool) with a big "VS" badge, a choice cursor hovering between them, then B lights up. Never show fake poll percentages. Each episode a different "arena" skin so the series doesn't feel copy-pasted: 086 boxing card, 087 retro arcade select, 088 postcard vs office, 089 vending choice buttons, 090 coin flip.
**Music:** trap (145); `whoosh` on the split, `swoosh_hit` on VS, `right` when B wins.
