# F13 — Raio-X (101–105)

**Lever:** picture superiority (people remember images far better than words) + curiosity about the mechanism ("how does it actually work?") + perceived competence. Explaining *how* builds trust without claiming anything new.
**Look:** blueprint / technical drawing: deep navy or aubergine paper with a fine grid, cyan/lavender line art drawn on with DrawSVG, dimension lines, callout leaders with numbered tags "①②③", "FIG. 1", a title block in the corner ("KIZUBOT — DESENHO TÉCNICO — FOLHA 1/5"). The robot from the logo can appear as a line-art trace (an SVG outline you draw by hand, simplified) next to the real logo. Real prints appear as "anexos" pinned to the sheet.
**Music:** synthwave (104) or tension (96) at mid energy; `type` for labels, `tick` per callout, `whoosh` on page turns.
**Facts:** only from BRIEF.md (modules, changelog facts).
