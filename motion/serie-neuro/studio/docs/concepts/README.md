# The 100-short bible (041–140)

Twenty recurring **series** × five episodes. A series is a repeatable format with its own visual system and one core neuromarketing lever; episodes change the content. Recurring formats are how short-form channels grow: viewers recognise the format in 0.5 s, binge the series, and the brand gets repeated exposure (mere-exposure effect). Every episode still has to work alone.

Production agents: read only your two series files (`F01-*.md` …), plus the shared docs listed in PRODUCTION.md.
Episode IDs are fixed. Folder name: `shorts/<id>-<slug>/` with the slug given in each episode.
Assets are referenced by their **source file name**; use the privacy-safe version listed in `docs/ASSETS.md` (look up the source name there). If an asset an episode needs was excluded, pick the closest allowed alternative and note it in meta.json.
Durations are targets (15–25 s); a tighter cut always wins.
